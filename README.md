# GLOBAL-CYBER-SECURITY-THREATS-A-2020-2024-ANALYSIS
Global Cybersecurity Threats: A 2020–2024 Analysis is a data analytics and visualization project that investigates the patterns, scale, and impact of cyber attacks worldwide over a five-year period. Developed using Tableau and grounded in real-world data sourced from Kaggle, this project translates raw security incident records into an interactive, multi-layered dashboard that makes complex threat intelligence accessible and actionable.
The dataset encompasses critical dimensions of cybersecurity incidents including the country of occurrence, year, attack type, targeted industry, financial loss, number of affected users, attack source, exploited vulnerability type, defense mechanism employed, and incident response time. These variables together paint a comprehensive picture of the global threat environment from 2020 through 2024.
The Tableau dashboard features a variety of chart types — including a world map, bar charts, line charts, bubble charts, area charts, and bar-line combo charts — each selected to best represent the underlying data. Colour encoding, filters, and sorting are applied throughout to enhance clarity and allow for meaningful comparisons across countries, years, and industries.
Key findings from the analysis reveal that Healthcare and Banking consistently faced the highest financial losses, while Phishing and DDoS remained the most prevalent attack types across all years. Nation-state actors emerged as a dominant attack source, and Zero-day vulnerabilities along with unpatched software were the most frequently exploited weaknesses. The data also indicates a steady year-over-year rise in the number of incidents, with attack volumes peaking noticeably in 2023 and 2024.
On the defense side, AI-based detection systems demonstrated competitive incident response times compared to traditional tools such as firewalls and antivirus software, suggesting a growing role for intelligent automation in cybersecurity operations.
This project serves as a valuable resource for cybersecurity analysts, students, researchers, and organizations seeking to understand threat trends and strengthen their security posture. It highlights key risk areas, supports evidence-based strategic planning, and promotes greater awareness of the evolving cyber threat landscape — laying the foundation for more resilient and informed digital defense strategies in the years ahead.
